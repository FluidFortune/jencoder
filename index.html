How JenCoder Works

JenCoder is the browser-based IDE for Pisces Moon OS P4 — the dual-MCU implementation targeting boards with an ESP32-P4 application processor and an ESP32-C6 always-on radio coprocessor.

The reference board is the ELECROW CrowPanel Advanced 7" — a $46 ESP32-P4 dev board with a 1024×600 MIPI-DSI touchscreen and an onboard C6.

If you're coming from Lety, the workflow is the same. The language changes from Arduino C++ to C, and the build system changes from PlatformIO to ESP-IDF.

Three workflow paths

  • ⚡ Build & Flash — Cloud or local backend runs idf.py build → returns a .bin → flashes via Web Serial. Requires Chrome, Edge, or Opera on desktop.
  • ⊞ Export — Generates pm_app_*.c + pm_app_*.h + integration.txt as a zip you can drop into a local clone of the pisces-moon-os-p4 tree and build with VS Code + the Espressif IDF extension.
  • 📋 Copy — Plain source to the clipboard for fast paste into your editor of choice.

The app contract

Every app on Pisces Moon P4 implements the pm_app_t struct:

typedef struct {
    const char*    id;
    const char*    display_name;
    pm_category_t  category;
    uint16_t       icon_id;

    void (*init)(void);
    void (*enter)(void);
    void (*tick)(uint32_t elapsed_ms);
    void (*exit)(void);
    void (*deinit)(void);
} pm_app_t;

init() runs once at boot; enter() runs whenever the user opens the app; tick() is periodic; exit() on back.

UI is LVGL via the pm_ui kit

Apps build their screen by calling pm_ui_screen(), pm_ui_titlebar(), pm_ui_card(), pm_ui_kv_row(), etc. The kit enforces a coherent look across all 56+ apps.

Modular hardware via pm_peer

Apps don't ask "is there a PN532 attached?" — they ask "is there an nfc_read peer available?":

pm_peer_t* p = pm_peer_find("nfc_read", PM_PEER_ROLE_ANY);
if (p) {
    pm_peer_call(p, "read_tag", NULL);
} else {
    // graceful "no NFC available" branch
}

Preview limitations

  • The preview is an HTML/CSS renderer of the LVGL widget kit. Layout, colors, text, kv-rows, lists, log panels, buttons, chips, status dots, meter bars, keypads — all rendered.
  • Hardware (real WiFi/BLE/LoRa/NFC/GPS/Camera) is replaced by deterministic mocks in jencoder_peer.js. Scanners show fake networks; GPS walks slowly around a fixed origin; NFC tags cycle.
  • Real-time SD I/O is stubbed but file paths are plumbed.
  • Heavy custom LVGL calls outside the pm_ui_* kit may render approximately but will compile fine for hardware.

Companion projects

JenCoder Web Edition is the browser counterpart to JenCoder (the desktop tool running inside Jennifer OS). The two share the same C source format and templates. Anything you build here drops into Jennifer OS unchanged.
